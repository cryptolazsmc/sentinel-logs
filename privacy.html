Privacy Policy — Sentinel Logs YouTube Connector

Effective 2026-10-11.

Who operates this application

The Sentinel Logs YouTube Connector ("the Connector") is a private, single-user desktop application operated by the owner of the YouTube channel Sentinel Logs (the "User"). Its only user is the channel owner. Contact for privacy questions: atlassentinelogs@gmail.com.

Use of YouTube API Services

The Connector uses YouTube API Services. By using the Connector, the User agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed, and why

Through the OAuth scopes youtube and youtube.upload, the Connector can access the User's own YouTube channel data (channel identity and metadata, video metadata) solely to: (a) verify that the connection points to the User's own channel; (b) read channel information for the User's own records; and (c) upload or manage videos on the User's own channel, only when the User explicitly authorizes that action. No other person's data is accessed.

Storage

The OAuth refresh token — the credential that keeps the connection alive — is stored only in an encrypted secure vault. Short-lived access tokens exist only in memory while the Connector runs. Channel data retrieved through the API is kept in the User's own private records. Credentials are never published, committed to a public repository, or shared.

Sharing

Data accessed through YouTube API Services is not sold, rented, or shared with third parties, is not used for advertising, and is not transferred except as necessary to operate the Connector for the User. The Connector's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Revoking access

The User can revoke the Connector's access at any time from Google's security settings page (myaccount.google.com/permissions). Revocation immediately stops the Connector from accessing the channel; stored credentials are then deleted from the vault.
